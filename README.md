StayManager – Repository Layer Development
"We developed a new Repository Layer in the StayManager application to improve database interaction and maintain proper separation of concerns.

The Repository Layer is responsible for communicating with the database using Spring Data JPA. We created repository interfaces for different entities and implemented database operations such as saving, retrieving, updating, and deleting records.

We used Spring Data JPA and Hibernate to simplify database operations and reduce boilerplate code. The Service Layer communicates with the Repository Layer, while the Controller Layer handles incoming API requests."
